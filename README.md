# LRX — segunda versão

Segunda exploração do conceito LRX, com uma nova direção visual para a apresentação de serviços automotivos.

## Relação com a primeira proposta

Este repositório registra uma alternativa de apresentação. As decisões sobre o que será mantido ou descartado devem ser feitas após comparar as duas direções com o responsável pelo negócio.

## Situação

O repositório ainda não recebeu os arquivos de código; por enquanto, registra a ideia. O GitHub só poderá identificar linguagens depois que a aplicação for versionada.

## Etapa seguinte

Definir o conteúdo comercial, escolher a direção visual e reunir imagens autorizadas antes de iniciar a implementação.
